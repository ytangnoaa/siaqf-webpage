# siaqf-webpage
SIAQF webpage

## GitHub Pages deployment

Before running the deployment workflow, a repository administrator must enable
GitHub Pages in **Settings → Pages** and select **GitHub Actions** as the build
and deployment source. The workflow's `GITHUB_TOKEN` cannot enable Pages itself.
After changing the setting, rerun the failed workflow from the Actions tab or
run **Deploy static content to Pages** manually.

The published page is available at the Pages site URL followed by `siaqf.html`.
